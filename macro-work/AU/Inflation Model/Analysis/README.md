# Australian inflation forecast analysis

[Read the PDF](inflation_analysis.pdf) or edit [the LaTeX source](inflation_analysis.tex). The report presents results first, followed by the model and data method.

Compile from this folder with `pdflatex -interaction=nonstopmode -halt-on-error inflation_analysis.tex`. The source includes the saved chart by relative path. Rerun the model and chart generator before updating the numerical table in the report.
