# KR SMOG figures

These charts are generated by [kr_smog_figure_generation.py](../../code/kr_smog_figure_generation.py) using the local [smoothed](../smog_kr_python.csv) and [filtered](../smog_kr_filtered_states.csv) states and observed unemployment from the `Update` tab of [KR SMOG Model Inputs.xlsx](../../code/KR%20SMOG%20Model%20Inputs.xlsx).

- [Output gap — smoothed](kr_smog_output_gap_smoothed.png) and [filtered](kr_smog_output_gap_filtered.png): output relative to potential, in per cent.
- [Unemployment and NAIRU — smoothed](kr_smog_unemployment_and_nairu_smoothed.png) and [filtered](kr_smog_unemployment_and_nairu_filtered.png): observed unemployment and the model's NAIRU, in per cent.
- [Unemployment gap — smoothed](kr_smog_unemployment_gap_smoothed.png) and [filtered](kr_smog_unemployment_gap_filtered.png): NAIRU minus observed unemployment, in percentage points. Negative values indicate unemployment above the NAIRU.

Smoothed states use the full available sample. Filtered states use observations only through each plotted quarter, with fitted coefficients held fixed. The charts currently end at **2026Q1**.
