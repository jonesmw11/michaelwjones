# AU SMOG figures

These PNGs are generated by [au_smog_figure_generation.py](../../code/au_smog_figure_generation.py) from the [smoothed](../smog_au_python.csv) and [filtered](../smog_au_filtered_states.csv) model states and observed unemployment in the `Update` tab of [AU SMOG Model Inputs.xlsx](../AU%20SMOG%20Model%20Inputs.xlsx). A grey horizontal line marks zero on each chart. Smoothed estimates use the full available sample at each date; filtered estimates use observations only through that date, with coefficients held fixed.

- [Unemployment-implied output gap — smoothed](au_smog_output_gap_smoothed.png): the model's unemployment-informed estimate of output relative to potential, in per cent.
- [Unemployment-implied output gap — filtered](au_smog_output_gap_filtered.png): the same estimate using observations only through each date.
- [Unemployment and NAIRU — smoothed](au_smog_unemployment_and_nairu_smoothed.png): observed unemployment versus the model's estimated non-accelerating inflation rate of unemployment.
- [Unemployment and NAIRU — filtered](au_smog_unemployment_and_nairu_filtered.png): observed unemployment versus the filtered NAIRU estimate.
- [Unemployment gap — smoothed](au_smog_unemployment_gap_smoothed.png): smoothed NAIRU minus observed unemployment, in percentage points.
- [Unemployment gap — filtered](au_smog_unemployment_gap_filtered.png): filtered NAIRU minus observed unemployment, in percentage points.

With this chart's sign convention, a negative gap means unemployment is above the model's NAIRU (slack), while a positive gap means it is below (tightness). All six charts end at the latest complete model quarter, currently 2026Q1, with no forecast period shown. Running the update script after adding complete quarters to the workbook's `Update` tab regenerates them. Run the figure script directly to regenerate them without updating the states.
