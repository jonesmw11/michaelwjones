# Macro-work archive

This folder contains material retained for provenance or possible reconstruction but not required by the active country-model workflows.

- `Core Inflation Collection/` contains the former combined four-country core-inflation workbook and the scripts, raw sources, catalogues and checks used to build it.

The separate country workbooks remain active inside each country's `Inflation Model` folder. Restore the archived collection to its former top-level location before attempting to rerun its scripts because their paths are preserved for reference rather than maintained as an active pipeline.
