# Japanese SMOG analysis

[Read the PDF](smog_analysis.pdf) or edit [the LaTeX source](smog_analysis.tex).

Compile from this folder with `pdflatex -interaction=nonstopmode -halt-on-error smog_analysis.tex`. The source includes all three saved model charts by relative path. Run generation and update before refreshing the numerical tables by hand. Build byproducts stay here and are ignored by Git.
