# Macro work

Macroeconomic research and coding projects.

- [Inflation forecasts](inflation-forecasts/README.md) — standalone VAR forecasts and charts for Australia, Japan, and Korea, with country-specific input workbooks.

- [AU SMOG Model](AU%20Smog%20Model/README.md) — Australian output-gap, potential-output, and NAIRU model, with code, inputs, saved results, and documentation.
- [KR SMOG Model](KR%20SMOG%20Model/README.md) — standalone South Korean output-gap, potential-output, and NAIRU model, with code, inputs, saved results, and figures.

- [JP SMOG Model](JP%20SMOG%20Model/README.md) — standalone Japanese output-gap, potential-output, and NAIRU model, with Python estimation, inputs, convergence diagnostics, and figures.

Create a separate folder for each project, with its code, supporting materials, and a README explaining the question, methods, results, and how to run the analysis. The [project README template](../templates/project-README.md) provides a starting point.
