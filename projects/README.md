# Research and coding projects

Project code will be added here. The research paper and CV are available from the [main portfolio](../README.md).

## Adding a project

1. Create a folder here with a descriptive name, such as `time-series-forecasting`.
2. Copy the [project README template](../templates/project-README.md) into that folder and rename it `README.md`.
3. Add your code, notebooks, dependency file, and selected results. Include data only if you have permission to publish it.
4. Replace the template prompts with a description of your work, then add a link to the project below.
