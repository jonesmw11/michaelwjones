# Project title

Replace the prompts below with your own project details before publishing the project.

## Overview

What question does the project address, and why does it matter? Summarise your contribution in a few sentences.

## Data

Describe the source, coverage, key variables, and any preprocessing. Link to the original data where possible. If data cannot be shared, explain how readers can obtain it or use a suitable example dataset.

## Methods

Explain the statistical or computational approach, important assumptions, and any comparison methods or baselines.

## Results

Present the main findings with a small number of figures, tables, or metrics. Explain how you evaluated the results.

## Limitations

Describe uncertainty, constraints, and what you would investigate next.

## Reproducing the analysis

Specify the language and version, dependencies, installation commands, and the exact commands or notebook order needed to reproduce the results. Note any required data downloads or configuration.

## Files

Explain the purpose of the main scripts, notebooks, and output folders.

## References and attribution

Cite relevant papers, data sources, and third-party code. For collaborative work, identify your contribution.
